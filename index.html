خطوات ربط المشروع في GitHub ورفع الموقع

استضافة التطبيق مجاناً عبر GitHub Pages:

# رفع الملف إلى المستودع

git init

git add index.html

git commit -m "إطلاق بطاقة اليوم الذكية"

git branch -M main

git remote add origin https://github.com/USERNAME/REPO_NAME.git

git push -u origin main

  1. احفظ الملف باسم index.html.
  2. من مستودعك في GitHub اذهب إلى Settings ثم Pages.
  3. تحت قسم Branch اختر main واضغط Save.
