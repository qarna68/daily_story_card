خطوات ربط المشروع في GitHub ورفع الموقع

يمكنك استضافة هذا التطبيق مجاناً وبنقرة واحدة عبر GitHub Pages كالتالي:

# 1. إنشاء مستودع جديد ورفع الملف

git init

git add index.html

git commit -m "إطلاق تطبيق بطاقة اليوم الذكية"

git branch -M main

git remote add origin https://github.com/USERNAME/REPO_NAME.git

git push -u origin main

  1. احفظ هذا الكود كملف وحيد باسم index.html.
  2. ادخل على إعدادات المستودع في GitHub (Settings).
  3. من القائمة الجانبية اختر Pages.
  4. تحت قسم Branch اختر main واضغط Save.
  5. سيصبح التطبيق متاحاً فوراً على رابط مجاني يدعم متصفح سفاري للآيفون!
